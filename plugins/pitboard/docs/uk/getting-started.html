Початок роботи з PitBoard

PitBoard малює рядок стану біля промпту: у CLI під ним, у Desktop над ним. Він показує, наскільки заповнений контекст, скільки ще живе кеш промпту і як швидко витрачаються ліміти використання. Сірий означає: працювати далі.

КороткоВстановити плагін і почати нову сесію: рядок з'явиться під промптом у CLI і над ним у Desktop. Сірий означає, що все гаразд; жовтий і червоний вказують, який показник потребує уваги. Порівняння Pace з Budget на ліміті показує, чи вистачить його до скидання.

Встановлення

  1. Встановити плагін

    /plugin install pitboard@agentpit

    Потрібен Claude Code 2.1.287 або новіший. PitBoard не записує жодного файлу, зокрема settings.json.

  2. Почати нову сесію

    Рядок завантажується на старті сесії: у CLI під промптом, із ⓘ і кнопкою pitboard у кінці; у Desktop над промптом як смуга з невеликих індикаторів, а кнопка pitboard стоїть у нижній панелі під промптом.

  3. Відкрити всі картки командою /pitboard

    /pitboard

    Виконати команду або клацнути кнопку pitboard, коли потрібні всі пояснення одразу, картка, яку обрізає вузький термінал, або показники в мобільному застосунку Claude, де панель є єдиним виглядом і відкрити її може лише команда.

    Показати панель для рядка нижче, у CLI або в Desktop

Чотири групи, зліва направо

Рядок однаковий у CLI та в Desktop; кожен показник пояснено на сторінці анатомії рядка.

Контекст

Наскільки заповнений контекст відносно точки, у якій Claude Code його стискає.

Кеш

Скільки часу лишилося до закінчення терміну кешу промпту і яка частина останнього ходу прийшла з нього.

Ліміти

П'ятигодинний і тижневий ліміти використання, а також, коли увімкнено usage-watch від PaceLine, тижневий ліміт для однієї родини моделей.

Сесія (ⓘ)

Модель, effort, радник, гілка, час роботи та вартість за цінами API. У CLI відкривається клацанням, у Desktop наведенням. Поки радника задано, обидва рядки також показують його окремою групою між Ctx і Cache з позначкою (inactive), якщо його модель слабша за основну.

П'ять термінів

Вони з'являються в картках лімітів. Кожен з них PitBoard обчислює з показників, які повідомляє Claude Code.

Як вони змінюються, показано на сторінці анатомії рядка

Разом із PaceLine

Якщо встановлено й PaceLine, PitBoard також читає файл лімітів PaceLine. Тоді нова сесія одразу показує ліміти, а Pace має історію з першого малювання.
